# Реестр полей Telegram Desktop 7.4.1

[palette.tsv](palette.tsv) содержит все 586 объявлений палитры с номером строки и исходным значением. Значения с `|` относятся к синтаксису исходной палитры. Экспорт в пользовательский файл должен соблюдать синтаксис загрузчика тем. [Палитра lib_ui](https://github.com/desktop-app/lib_ui/blob/42c6f1e88db81e6d9e8006f3e7b1c3ba39f9cac4/ui/colors.palette), [подключение палитры при сборке](https://github.com/telegramdesktop/tdesktop/blob/157f5cfc85e2dd1fa67f129a5e31a81db5ddeb19/Telegram/cmake/td_ui.cmake#L91)

[fields.tsv](fields.tsv) перечисляет три поля облачного редактора и четыре допустимых имени файла встроенных обоев. Четыре имени представляют варианты одного ресурса. Палитра в ZIP хранится в `colors.tdesktop-theme` или `colors.tdesktop-palette`. Имена контейнера и палитры описывают упаковку темы. [Облачные темы](https://core.telegram.org/themes), [загрузчик темы](https://github.com/telegramdesktop/tdesktop/blob/157f5cfc85e2dd1fa67f129a5e31a81db5ddeb19/Telegram/SourceFiles/window/themes/window_theme.cpp#L273)

В Shibuya Ink найдены все 586 ключей этой палитры, три поля облачной темы и ещё 20 имён, отсутствующих в палитре 7.4.1. Загрузчик допускает произвольные вспомогательные имена для ссылок на цвета. Такие записи нужно учитывать при импорте и проверять по их использованию в файле.

## Как обновлять привязки

[coverage.tsv](coverage.tsv) задаёт одну основную задачу T012–T017 для каждого ключа и хранит комментарий из закреплённой палитры. Дефис означает, что у ключа нет комментария. Группы основаны на разделах палитры и назначении ключей. Например, цвета папок отнесены к списку чатов, а цвета панели звонка — к звонкам. Основная задача определяет порядок работы над ключом. Подтверждённые привязки этого ключа могут относиться к нескольким компонентам.

В [bindings.tsv](bindings.tsv) одна строка соответствует свойству компонента в конкретном состоянии. Ключ может встречаться в нескольких строках, если он управляет несколькими свойствами. Одна комбинация `component + state + property` допускает одну привязку. Перед добавлением строки проверь существующие записи по ключу и по этой комбинации.

- `source` указывает место отрисовки или определение стиля в закреплённой версии клиента. Запиши понятное описание эффекта в `description`.
- В `implementation` укажи путь к реализованному примеру. До его появления используй `-`.
- В `verification` укажи проверку, подтвердившую эффект в целевом клиенте, и её результат. До проверки используй `-`.

Проверка и отчёт выполняются без GUI и сетевого доступа из корня репозитория.

```sh
python3 scripts/check_catalog.py
python3 scripts/check_catalog.py --report
```

Команда без аргументов показывает число ключей в каждой группе и сколько из них имеют хотя бы одну описанную, реализованную или проверенную в клиенте привязку. `--report` выводит по одной строке на поле. Столбцы `mapped`, `implemented` и `verified` считают привязки, а `editable` равен единице, если ключ можно изменить в редакторе. Сейчас правка доступна через реализованные предпросмотры. T011 добавит правку всех ключей через каталог. Проверенная привязка подтверждает эффект в конкретном состоянии. У того же ключа могут быть другие места использования.

При обновлении версии сначала сверь gitlink `Telegram/lib_ui` новой версии, скачай палитру соответствующего коммита и сравни ключи перед обновлением реестра и контрольных сумм. Для текущей версии сверка воспроизводится так.

```sh
curl -fsSL https://raw.githubusercontent.com/desktop-app/lib_ui/42c6f1e88db81e6d9e8006f3e7b1c3ba39f9cac4/ui/colors.palette -o /tmp/telegram-7.4.1-colors.palette
python3 scripts/check_catalog.py --upstream /tmp/telegram-7.4.1-colors.palette
```
