# План gui-tg-theme-creator

Цель — выбрать визуальный элемент Telegram Desktop, изменить его цвет и получить файл темы, пригодный для применения в клиенте.

## Полное покрытие палитры Telegram Desktop 7.4.1

Отправная точка — 586 ключей в реестре, у 20 из них есть реализованные привязки. Проверки обычного и заглушённого счётчиков в клиенте записаны в T008. Остальные 566 ключей пока доступны в каталоге для просмотра. Семь дополнительных полей и вариантов обоев учитываются отдельно от палитры.

Критерий этапа — каждый из 586 ключей можно найти, отредактировать и сохранить в `.tdesktop-theme`. Для каждого ключа с подтверждённым визуальным эффектом в целевом клиенте нужен пример либо указание на конкретное условие его появления и способ проверки. Для ключей, доступных только на другой платформе, в определённом режиме или без найденного места использования, в каталоге нужны статус и основание из исходников.

Задачи по компонентам выполнять по порядку. Для каждой группы записывать в реестр проверенные привязки, добавлять примеры состояний и проверять изменения на синтетической палитре с различимыми цветами. Для общих ключей проверять обновление во всех связанных примерах. Проверку в браузере и подтверждение в Telegram Desktop отмечать отдельно. При необходимости группу можно разбить на меньшие задачи до начала её реализации.
