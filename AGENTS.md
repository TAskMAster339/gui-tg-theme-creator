# gui-tg-theme-creator

Локальный графический редактор тем Telegram Desktop для Linux. Пользователь выбирает видимый элемент, меняет его цвет, сразу видит результат и экспортирует применимую тему.

## Первая версия

Отдельное приложение с интерактивными примерами компонентов Telegram Desktop. Пользователь открывает свою тему или начинает с базовой палитры клиента. Каждая строка редактора посвящена одному компоненту. Слева расположены названия и описания свойств, ключи палитры и инструменты изменения цвета. Справа расположен живой пример с переключением применимых состояний. Клик по части примера выделяет связанное свойство слева. Изменения сразу видны во всех примерах, использующих тот же цвет.

Стек — Python и PySide6. Целевой клиент для первой проверки — Telegram Desktop 7.4.1 (Flatpak), установленный локально. Поддерживаем импорт текстовых палитр и ZIP-архивов темы, экспорт в `.tdesktop-theme` и проверку файла в клиенте. Для публикации используем штатный сценарий облачных тем Telegram.

## Границы компонентов

- Чтение и запись форматов темы работают независимо от GUI и не меняют исходный файл.
- Модель палитры разрешает ссылки между ключами и показывает, какие элементы используют общий цвет.
- Каталог компонентов связывает визуальные свойства и состояния с ключами палитры. Для каждой привязки указывай источник в целевой версии Telegram Desktop. Показывай ключи, для которых назначение ещё не подтверждено или пример ещё не добавлен. Сохраняй такие ключи при экспорте.
- Интерфейс редактирует модель, обновляет предпросмотр и экспортирует результат в выбранный файл.

## Цикл разработки

Перед изменениями прочитай [PLAN.md](PLAN.md) и [.skills/README.md](.skills/README.md). Выбери одну задачу в рамках запроса. Проверь её критерий приёмки, обнови чекбокс, просмотри staged diff и сделай отдельный локальный коммит. Оставь открытой задачу, для которой проверка ещё не пройдена. При паузе запиши следующий шаг под задачей.

Для изменений каталога запускай `python3 scripts/check_catalog.py` и `git diff --check`. Порядок обновления привязок описан в [catalog/README.md](catalog/README.md). Не используй личные данные Telegram как тестовые образцы.
