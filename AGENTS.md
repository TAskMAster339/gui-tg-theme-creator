# gui-tg-theme-creator

Локальный графический редактор тем Telegram Desktop для Linux. Пользователь выбирает видимый элемент, меняет его цвет, сразу видит результат и экспортирует применимую тему.

## Первая версия

Рабочее предложение для согласования — отдельное приложение с интерактивным предпросмотром Telegram Desktop. Начальные экраны включают чат, список чатов, боковое меню, настройки и профиль канала. Проверь с пользователем, достаточно ли предпросмотра или нужен выбор элементов в запущенном клиенте. От этого зависит архитектура.

Предлагаемый стек для отдельного приложения — Python и PySide6. Qt подходит для нативного окна на KDE Plasma и Niri и позволяет проверять интерфейс без запуска Telegram. Решения о режиме выбора и стеке фиксируются в T002 до реализации.

## Границы компонентов

- Чтение и запись форматов темы работают независимо от GUI и не меняют исходный файл.
- Модель палитры разрешает ссылки между ключами и показывает, какие элементы используют общий цвет.
- Предпросмотр связывает области экрана и их состояния с ключами палитры. Проверяй привязки по исходникам целевой версии Telegram Desktop.
- Интерфейс редактирует модель, обновляет предпросмотр и экспортирует результат в выбранный файл.

## Цикл разработки

Перед изменениями прочитай [PLAN.md](PLAN.md) и [.skills/README.md](.skills/README.md). Выбери одну задачу в рамках запроса. Проверь её критерий приёмки, обнови чекбокс, просмотри staged diff и сделай отдельный локальный коммит. Оставь открытой задачу, для которой проверка ещё не пройдена. При паузе запиши следующий шаг под задачей.

Сейчас доступна проверка `git diff --check`. Команды тестирования, проверки стиля и запуска добавляются после выбора стека. Не используй личные данные Telegram как тестовые образцы.
