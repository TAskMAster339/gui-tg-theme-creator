# Редактор тем Telegram Desktop

Браузерный редактор тем с предпросмотром компонентов. Текущий каркас показывает ключ и базовый цвет точки непрочитанного в шести состояниях чата.

## Запуск

Требуется Node.js 22.12+ в ветке 22 или Node.js 24+.

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite.

## Проверки и сборка

```sh
npm run check
npm run build
python3 scripts/check_catalog.py
```

`npm run build` собирает статические файлы в `dist/`. Локально проверить сборку можно через `npm run preview`. Python нужен для проверки каталога в ходе разработки.
