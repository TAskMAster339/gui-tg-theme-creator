# Редактор тем Telegram Desktop

Браузерный редактор тем с предпросмотром компонентов. Предпросмотр показывает цвет точки непрочитанного в шести состояниях чата. Через «Открыть тему» можно загрузить текстовую палитру или ZIP-тему. Обработка выполняется локально в браузере. «Базовая палитра» возвращает исходные цвета Telegram Desktop.

## Запуск

Требуется Node.js 22.12+ в ветке 22 или Node.js 24+.

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite.

## Проверки и сборка

```sh
npm run check
npm run build
python3 scripts/check_catalog.py
```

`npm run build` собирает статические файлы в `dist/`. Локально проверить сборку можно через `npm run preview`. Python нужен для проверки каталога в ходе разработки.
