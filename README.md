# Редактор тем Telegram Desktop

Браузерный редактор тем с предпросмотром компонентов. Предпросмотр показывает цвета компонентов списка чатов, переписки, канала, меню и настроек. В каталоге ключей видны подтверждённые привязки и ссылки на исходники Telegram Desktop. Через «Открыть тему» можно загрузить текстовую палитру или ZIP-тему. Обработка выполняется локально в браузере. «Базовая палитра» возвращает исходные цвета Telegram Desktop. Кнопка «Скачать .tdesktop-theme» сохраняет текущую палитру и вложения импортированной ZIP-темы.

## Запуск

Требуется Node.js 22.12+ в ветке 22 или Node.js 24+.

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite.

## Проверки и сборка

```sh
npm run check
npm run build
python3 scripts/check_catalog.py
```

`npm run build` собирает статические файлы в `dist/`. Локально проверить сборку можно через `npm run preview`. Python нужен для проверки каталога в ходе разработки.
